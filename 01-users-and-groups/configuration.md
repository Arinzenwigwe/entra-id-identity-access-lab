# Users and Groups Configuration

## 1. Objective

This exercise demonstrates the creation and management of
users and security groups in Microsoft Entra ID.

## 2. Scope

- Create test user accounts.
- Create security groups.
- Assign users to appropriate groups.
- Verify group membership.
- Review user properties and account status.

## 3. Lab Environment

- Platform: Microsoft Entra ID
- Subscription: Microsoft 365 E3
- Environment: Laboratory tenant

## 4. Implementation

Status: Planned

The following activities will be performed:

1. Access Microsoft Entra Admin Center.
2. Navigate to Identity > Users > All users.
3. Create designated test accounts.
4. Navigate to Groups > All groups.
5. Create security groups.
6. Add test users to the appropriate groups.
7. Verify configurations.
