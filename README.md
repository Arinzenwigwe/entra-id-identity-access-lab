# Microsoft Entra ID – Identity and Access Management Lab

## 1. Project Overview

This project demonstrates practical implementation and administration of Microsoft Entra ID identity and access management capabilities in a Microsoft 365 laboratory environment.

The lab focuses on identity security, administrative privilege management, access control and authentication security.

## 2. Project Objectives

- Create and manage users and security groups.
- Establish administrative tiers and role separation.
- Configure named locations.
- Implement Conditional Access policies.
- Configure Privileged Identity Management (PIM), subject to licensing availability.
- Test and document identity and access security configurations.
